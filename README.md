# Fledermauskolonie

Ein kleines Aufbauspiel im Stil von Kittens Game: eine Fledermauskolonie wächst, Nacht für Nacht.
Läuft im Browser, am PC und am Handy (zum Startbildschirm hinzufügen, dann auch offline).

Lokal: `python serve.py 8933`, dann http://localhost:8933 · Tests: `node test.js` · Tempo: `node test.js tempo`
